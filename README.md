# KCL sample course

**Live site:** https://aidacarlon01.github.io/kcl-sample-course/

A sample Canvas-style course demonstrating the theme and component set built for two
Career Accelerator programmes delivered with King's College London on Canvas LMS — a
companion artefact for the portfolio case study *King's College London programmes in
Canvas LMS*.

Five pages (home + four), each built from the authored components with copy that
explains the component itself: banner, wells, notes, pull quotes, download buttons,
overview cards, video with on-page transcript, figures with alt-text guidance, the
accordion rebuilt on native HTML, and glossary terms defined in place.

**A sample course, not a real one.** The stylesheet and script are reconstructions
made for this portfolio; all content is fictional, and no King's branding, logo or
course material is used.

See also: the [Monash-style sample course](https://aidacarlon01.github.io/interactive-catalogue/sample-course/)
and the [course production walkthrough](https://aidacarlon01.github.io/course-production-walkthrough/).
