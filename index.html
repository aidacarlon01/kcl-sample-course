Welcome to the sample course

A working course, built from the theme’s components, where the copy explains each component.

This sample shows the Career Accelerator theme the way a learner meets it: inside a course, page after page. Each page uses the authored components a learning technologist pastes into the Canvas Rich Content Editor, and the stylesheet and script that style and enhance them are reconstructions of the ones that ran in production. The only thing that changes is the copy — instead of subject content, each component describes what it is for and how to use it.

A course home page needs a small set of components: a page banner, a few paragraphs of welcome text, a video with its transcript, a note, a pull quote, and a set of cards that lead into the rest of the course. That is everything on this page, top to bottom.
